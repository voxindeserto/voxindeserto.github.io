重新設計一個網站，不只是改變外觀，更是重新思考自己希望如何在網絡世界中呈現自己。

過去，我一直透過個人網站分享自己的興趣、信仰、生活點滴與不同的創作。隨着時間過去，我對網站設計的想法也逐漸改變。我開始思考：一個真正適合自己的網站，應該具備甚麼特色？除了展示內容之外，它又能否更清晰地呈現自己的個人風格、專業技能與創作方向？

這些思考，成為我重新設計個人網站的起點。

## 從 WordPress 開始，重新思考網站的方向

最初，我使用 WordPress 建立個人網站。作為一套成熟的內容管理系統，WordPress 提供了相當方便的內容編輯方式，讓我不必從零開始編寫每一個網頁，也能逐步建立自己的網絡空間。

然而，隨着網站內容日益增加，我開始希望它不再只是一個發布文章的平台，而是能夠更完整地呈現自己的個人身份、興趣、作品與網上足跡。

我希望網站的設計更加簡潔，內容架構更加清晰，同時保留足夠的自由度，讓我可以按照自己的需要調整版面、編排文章，甚至自行修改網站的程式碼。

因此，我決定重新審視自己的建站方式，探索其他網站框架與程式語言，尋找一套更符合自己長遠需要的方案。

## 探索新的框架與程式語言

對我而言，網站設計一直不只是視覺上的工作，也是一個持續學習的過程。

過去，我曾接觸 HTML、CSS 和 JavaScript 等網頁技術，亦有使用 WordPress、DokuWiki、Blogger 和 Substack 等平台的經驗。這些經歷讓我逐漸理解網站如何組織內容、呈現資訊，以及透過不同工具建立和管理網絡空間。

這一次改版，我希望進一步探索靜態網站生成器（Static Site Generator），以及更現代化的網站開發方式。

與傳統需要在伺服器端即時處理內容的網站不同，靜態網站生成器可以預先將文章、版面模板與其他資源編譯成 HTML、CSS 和 JavaScript 等靜態檔案。這種方式不但有利於網站部署和版本管理，也讓我可以更直接地掌握網站的結構與運作方式。

經過一番探索，我最終選擇了 Hugo。

## 為甚麼選擇 Hugo 與 Blowfish？

Hugo 是一套以 Go 語言開發的靜態網站生成器，以建置速度快、內容管理靈活，以及適合建立個人網站和網誌等特點見稱。

對我而言，Hugo 最吸引的地方，是它能夠將文章管理、網站結構與版面設計清楚地分開。我可以使用 Markdown 撰寫文章，再透過主題與模板控制網站的呈現方式，而不必每次發布新文章時，都重新編寫整個網頁。

在選擇 Hugo 之後，我進一步採用了 Blowfish 作為網站主題。

Blowfish 是一套為 Hugo 設計的現代化主題，具備簡潔的視覺風格、靈活的版面配置，以及適合個人網站和內容創作的平台功能。它提供的自訂選項，讓我可以在保留整體設計一致性的同時，逐步調整網站的色彩、導覽、文章版面與其他細節。

我希望新網站既不會過分繁複，也不會失去個人特色。Blowfish 為我提供了一個合適的起點，讓我可以把更多心思放在內容、文字與作品本身，而不是每次更新都必須處理大量重複的設計工作。

當然，選擇現成主題並不代表完全依賴預設設計。對我來說，真正有趣的地方，正是透過研究主題的結構、修改設定，以及逐步理解背後的程式碼，讓網站慢慢發展成符合自己需要的模樣。

## 以 GitHub Pages 管理與發佈網站

在網站的建置過程中，另一個重要的環節，是如何管理網站的原始檔案，以及將完成的網站發布到互聯網。

我選擇使用 GitHub 儲存及管理網站的原始碼，讓文章、設定檔、主題配置與其他網站資源，都能夠透過版本控制系統妥善管理。

GitHub 不但方便我追蹤每次修改，也讓我可以在不同裝置上繼續處理網站，並在需要時回顧或還原過去的版本。

此外，GitHub Pages 是 GitHub 提供的靜態網站託管服務，讓使用者可以從 GitHub 儲存庫發布網站。對於以 Hugo 建立的個人網站而言，這類服務提供了一種管理與發布靜態網頁的方式。

透過版本控制與靜態網站生成器的配合，我可以更有系統地管理網站內容，亦能在修改設計或新增文章時，保留清晰的工作流程。

## 中文個人網站與英文作品集：不同的定位

除了這個中文個人網站，我亦設有自己的英文網站：https://www.chavezpoon.com

英文網站主要作為我的個人作品集與網誌，集中展示我在天主教媒體、數碼內容創作，以及相關項目中的工作與成果。

在那裡，我會整理自己的媒體作品、報道經驗、專業項目，以及其他值得分享的創作，讓讀者和有興趣合作的人士能夠更直接地了解我的工作。

除此之外，我亦建立了我自己的英文公教報道網站 [Lumen Orientale](https://lumen-orientale.github.io)，主要用作發佈由我本人撰寫的報道文章。

相較之下，這個中文網站則更著重個人的興趣、信仰、生活經歷，以及我對不同事物的觀察與思考。我希望透過中文，與讀者分享一些較為個人化的內容，也讓不熟悉我英文作品的人，能夠從另一個角度認識我。

兩個網站並不是互相取代，而是各有定位、互相補充。前者偏重專業作品與媒體工作，後者則保留更多個人色彩，記錄我在生活、信仰、學習與創作上的不同片段。

## 一個仍在發展中的網站

這次改版並不代表一切已經完成。對我而言，網站是一個可以持續發展的項目，而不是一件完成後便不再改變的作品。

隨着我對 Hugo、Blowfish 以及相關網頁技術的認識逐漸加深，我仍希望繼續改善網站的版面、導覽與閱讀體驗，並探索更多適合自己的功能。

每一次調整，都是一次重新學習的機會；每一項新技術，也讓我有機會重新思考自己建立網站的方式。

回顧這段過程，我最大的收穫並不只是換了一套網站框架，而是更加清楚自己希望透過網站做甚麼，以及如何運用技術，建立一個真正屬於自己的網絡空間。

新網站只是新的起點。至於接下來會加入甚麼內容、學習甚麼技術，又會有甚麼新的想法，仍有待日後慢慢探索。

感謝每一位到訪這裡的讀者。希望這個小小的網絡空間，能夠繼續記錄我的成長，也讓你在閱讀的過程中，發現一些值得思考與分享的事物。

願我們在探索與創作的路上，始終懷着好奇，也不忘自己出發的初心。
